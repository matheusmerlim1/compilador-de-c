Compilador de C

Escreva, compile e teste exercícios em C numa janela só — com os erros do compilador traduzidos para português e uma dica de como corrigir cada um.

Baixar para Windows Programar online Ver o código no GitHub

Windows 10/11 · 64 bits · ~10 MB · não precisa instalar Python
Sem instalar nada: escreva e rode C direto no navegador, e baixe o .c no fim.

#O problema

Quem está aprendendo C trava na mensagem do compilador, não no algoritmo.

o que o GCC responde 
media.c:7:5: error: expected '=', ',', ';', 'asm'
or '__attribute__' before 'float'
o que este programa mostra 
ERRO  linha 7
   Faltou um ponto e vírgula (;).
   original: expected '=', ',', ';', 'asm' ...
     6 |     float n1, n2, n3
   > 7 |     float media;
   como corrigir: O ; que falta está quase sempre no
   final da linha anterior, não na linha apontada.

#O que ele faz

Traduz o erro

Cerca de 30 erros comuns explicados em português, com a linha marcada em vermelho no editor e o que fazer para corrigir.

Console de verdade

O programa pergunta, você responde na hora — como no Code::Blocks. Com botão para parar o que travou.

Confere a resposta

Escreva os casos de teste num arquivo e ele compara a saída, mostrando exatamente a linha que divergiu.

Explica quando quebra

Segmentation fault, divisão por zero, laço infinito e estouro de pilha viram explicações, não códigos hexadecimais.

Pega o que o GCC ignora

Uma revisão própria alerta sobre armadilhas que compilam sem aviso, como scanf("%s", &letra) numa variável char.

Funciona online também

Dá para escrever e rodar C no navegador, sem instalar nada, e baixar o .c no fim. Compila de verdade: é o Clang em WebAssembly.

Abre pelo botão direito

Depois de instalado, qualquer arquivo .c pode ser aberto por Abrir com › Compilador de C.

#Como instalar

  1. Baixe o Compilador-de-C.exe Pelo botão no topo da página. É um arquivo só, não precisa de Python.
  2. Dê dois cliques nele O programa abre direto. Se quiser só testar, pode parar por aqui.
  3. Para instalar de verdade, rode o INSTALAR.bat Vem na pasta instalador/ do repositório. Cria os atalhos, registra o Abrir com e oferece instalar o GCC se faltar.
Não quer instalar nada? Use a versão online: escreve, compila e roda no próprio navegador, e baixa o .c no fim. O compilador (~58 MB) é baixado uma vez e fica guardado. A diferença é que online as entradas do scanf são preenchidas antes de rodar; no programa para Windows você digita durante a execução.
Precisa de um compilador C. Este programa é uma interface para o GCC — ele não substitui o compilador. Se o GCC não estiver na máquina, o instalador se oferece para baixá-lo pelo winget, e o próprio programa mostra o passo a passo. Instalação manual:

winget install -e --id BrechtSanders.WinLibs.POSIX.UCRT

#Como foi feito

Python 3 e Tkinter, chamando o GCC por baixo.

ccrun/editor.pya janela: editor, console e painéis
ccrun/diagnosticos.pytradução dos erros para português
ccrun/compilar.pychamada do GCC e escolha das flags
ccrun/executar.pyexecução com limite de tempo e leitura da falha
ccrun/testes.pyleitura dos casos e comparação de saída
ccrun/sem_buffer.cfaz as perguntas aparecerem na hora no console
ccrun/cli.pya mesma coisa por linha de comando

Compila sempre com -Wall -Wextra -Wshadow -Wformat=2, que pega vários erros de lógica antes do programa rodar, e já liga a biblioteca matemática — então sqrt e pow funcionam sem configurar nada.
